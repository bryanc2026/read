# Boom Coaching & Consulting

*Last updated: 2026-09-18*

## Basics

- Website (being rebuilt as of this update — see `/` in this repo,
  branch `claude/boome-coaching-redesign-odgane`): https://coaching.boomecommerce.com.au/
- Ownership: **50/50, Bryan and Iain**.
- Running since **August 2023**.
- Model: coaching community for Shopify/ecommerce founders and marketers,
  capped-capacity (20 brands), built around the "Your Numbers" system —
  see `lib/data.ts` in this repo for the full public-facing positioning,
  program structure, results, and coach bios already gathered from Bryan
